# Brick Shooter

Three.js 俯視角方塊人射擊，直式手機雙搖桿優先，也支援 WASD + 滑鼠。

- 手機：左半邊移動；右半邊瞄準（內圈 = 雷射瞄準，推過內圈 = 開火）；右半邊快速點一下 = 換彈
- 電腦：WASD 移動、滑鼠瞄準、左鍵開火、R 換彈、Q / 滾輪切換武器、E 換持槍手、Esc 暫停
- 武器與裝備：兩把槍，各自選彈種 → 槍機 → 槍托 / 彈匣 / 槍管 / 前握把；零件會互斥，影響威力、射程、後座力、轉向速度、重量
- 淡白線是想瞄的方向，雷射是槍口實際方向；越重轉得越慢、切槍越慢
- 被擊中 3 次就死，清光房間走進綠色出口
- 模式：清房模式（無限循環）、破門攻堅（貼著木門往前推 = 踹門 + 慢動作）、黑暗模式（只有手電筒和吊燈，殭屍成群，巨型殭屍會衝撞）

本機執行：`python -m http.server 8080`，開 http://localhost:8080（網址加 `?tick` 改用計時器跑主迴圈，視窗被藏起來時除錯用）
