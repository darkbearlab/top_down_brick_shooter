# Brick Shooter

Three.js 俯視角方塊人射擊，直式手機雙搖桿優先，也支援 WASD + 滑鼠。

- 手機：左半邊移動；右半邊瞄準（內圈 = 雷射瞄準，推過內圈 = 開火）；右半邊快速點一下 = 換彈；右側拇指上方的「滾」= 翻滾
- 電腦：WASD 移動、滑鼠瞄準、左鍵開火、空白鍵 / Shift / 右鍵翻滾（有冷卻，腳下的圈縮完才能再滾）、R 換彈、滾輪或 1 / 2 切換武器、Q 左手持槍、E 右手持槍、Esc 暫停
- 武器與裝備：兩把槍，各自選彈種 → 槍機 → 槍托 / 彈匣 / 槍管 / 前握把；零件會互斥，影響威力、射程、後座力、轉向速度、重量
- 淡白線是想瞄的方向，雷射是槍口實際方向；越重轉得越慢、切槍越慢
- 關卡目標：清光、打開所有開關、撐住幾秒、拿到物資撤離、救人質（不用清光，碰到就救出；之後人質跟著你走，被你打到或被敵人打 5 發就失敗，要帶到出口才算撤離）
- 機關：站上開關切換鐵捲門 / 燈；殭屍會敲門；吊燈打得掉；通風口會冒殭屍
- 推門（d）：走過去就推開、停在推開的角度，敵人也會推；關著擋視線和子彈，打得爛
- 警戒：槍聲沿著走道傳，關著的門會悶住一些；聽到的敵人往你這邊移動，路被木門擋住就在門後守著；發現你的敵人會喊人，附近同伴跟著警戒；敵人開槍也會吵醒附近的同伴
- 破壞：木門、磚牆、沙包每格切成 4×4 根小柱，子彈打哪根爛哪根，打穿的洞子彈、視線、人都過得去；巨型殭屍一撞就是大洞
- 敵人的子彈大多是看得到的慢速方塊彈丸（打到東西原地縮掉，不噴火花），一種敵人只會一種攻擊，衣服顏色 = 子彈顏色：射手（橘）瞄準三連發、散射兵（青）三向散射、重砲手（紫）五發扇形、環砲手（黃）一圈 10 發；只有狙擊手（綠）打快速彈，開槍前有雷射預告、最後 0.3 秒鎖定閃爍，一次一發。玩家用走位和翻滾閃避，翻滾前 0.3 秒無敵，彈丸直接穿過；玩家被彈丸打中的判定比身體小
- 鏡頭往瞄準方向偏：手機推右搖桿就往那邊看，沒推回正；電腦看游標離角色多遠，游標放回角色身上就回正
- 彈丸碰到沙包一定被擋下，順便打掉那塊沙包，躲久了掩體會被啃光
- 沙包對玩家的子彈是半掩體：擋路不擋子彈，但目標貼在沙包後面時，子彈有 75% 被擋下並打掉彈著點那塊（貼著但正在開火時只剩 20%）；那裡沒東西了就直接打中
- 地圖字元與關卡欄位說明在 src/rooms.js 開頭
- 被擊中 3 次就死，清光房間走進綠色出口
- 闖關模式（主選單第一個）：一局 = 連續的開放場地（大片空地加零散掩體，掩體互不相連、不貼外牆，不會圍出死角；越深越大）；開場幾乎沒有敵人（第 1 層 0 個），主要靠多波增援：每波 2～5 人、同一波分散在不同方向；場上剩 1 人以下或每隔 9～15 秒就來下一波，但場上人數有上限，從一把手槍開始；每張圖清完（含增援）走進出口後三選一（隨機拼出的槍、急救包、醫療箱；獎勵池在 src/run.js 的 REWARDS，各有權重）；最多帶兩把槍，撿槍要選放哪一欄，被換掉的就沒了；生命跨層保留，死了這一局結束
- 道具（闖關）：地圖重生型開場就在地上標出位置（同色淡圈加四角括號，快出現時越閃越快），到時間從地板冒出方塊組裝成道具、閃一下才撿得到（計時型被撿走後地標留著，原地再組裝一次）；敵人死掉有 8% 掉落，地上 12 秒沒撿就消失。急救包 +1 命、護甲（擋一下，最多 2 層）會帶到下一關、不重生；加速（移速 +30%）、強攻（威力 +50%）、快換（換彈兩倍快）是限時 buff，會重生，剩餘時間不帶到下一關。滿血 / 護甲滿時撿不起來，會留在地上；道具與時間表在 src/items.js、src/run.js
- 頭目關（暫定）：闖關每第 3 層是頭目關，沒有增援，玩家登場後頭目在正前方花 3.4 秒組裝出來（鏡頭往它偏），畫面最上方的血條（出現時 HUD 往下讓位）跟著從左到右一格一格組起來；受傷時掉光的格子碎掉噴開。頭目（方塊巨像）超巨大、碰到會受傷，輪流用連射、扇形、環形、螺旋、狙擊（雷射預告的快速彈）、衝撞（撞牆會暈），子彈顏色跟同招式的小兵一樣；血量 2/3、1/3 時叫兩個小兵組裝出來，一半以下暴怒（招式間隔變短、彈丸變多）。打倒後召喚的小兵一起倒，獎勵的槍至少精良。行為在 src/boss.js
- 登場：每一關開始時鏡頭拉近，玩家從地板冒出方塊組裝起來（約 1.15 秒，期間整個世界停住），組好閃一下才能動，鏡頭慢慢拉回原本距離；組裝演出共用 src/assemble.js
- 增援：場上剩 1 個敵人以下時，下一波從玩家附近（走得到、5～12 格）的地板冒出方塊往上組裝成敵人；組裝中打不到、沒有碰撞、可以穿過，完成那一刻站在上面會被彈開受傷，之後閃一下、停 0.55 秒才開始行動；一波最多一個散射類敵人
- 防彈衣：軀幹外包一圈灰色方塊，沒穿甲能力的子彈只剩 30% 傷害；精確射手步槍、機槍天生穿甲，其他槍要靠「穿甲彈」詞條
- 隨機拼槍：抽彈種 → 相容的槍機 → 每欄抽裝得上的零件；稀有度決定 0～2 個強化詞條（穿甲彈、貫穿、消彈、擴容、快拔、滾裝、連射、強裝藥）
- 模式：彈幕試玩場（兩間大的開放房間，鏡頭拉遠，敵人從遠處開始，試彈幕和翻滾手感；關卡可設 zoom）、清房模式（無限循環）、破門攻堅（貼著木門往前推 = 踹門 + 慢動作）、黑暗模式（只有手電筒和吊燈，殭屍成群，巨型殭屍會衝撞）
- 隨機任務（主選單 → 任務模式）：選地圖大小、敵人數量、可能抽到的任務（清除／救人質／搶物資／啟動開關／撐住）、一般或黑暗，自動產生房間、破門／推門、磚牆、掩體和敵人；可以填種子重玩同一張圖

- 角色工坊（電腦操作）：分部位（頭、身體、左右手、左右腳）像創造模式一樣堆方塊；每個部位只有 1～2 顆刪不掉的骨架核心當立足點（頭、身體在中心，手腳在肩膀／髖關節），其他方塊都能挖掉重堆；按住拖曳連續畫、1～5 格大小的筆刷、左右對稱、左右手腳一起改、上色、吸色、參考圖吸色（載入、拖放或貼上）、復原；造型碼可以複製分享
- 關卡編輯器（建議用電腦）：主選單進入，左鍵畫、右鍵擦、數字鍵換線路、中鍵或空白鍵拖曳移動畫面、Ctrl+滾輪縮放，地圖最大 60×60，擺物件、接開關線路、設定目標，可以預覽、直接測試，按「複製 JSON」貼給 Claude 加進「自訂戰鬥」

## 檔案
- `src/main.js` 進入點：遊戲流程、HUD、選單、主迴圈
- `src/core.js` 場景、燈光、共用狀態 `G`、輸入
- `src/world.js` 地圖、碰撞、可破壞格子、機關、關卡目標、載入關卡
- `src/player.js` / `src/enemies.js` / `src/bullets.js` / `src/fx.js` 玩家、敵人、子彈、特效
- `src/editor.js` 關卡編輯器；`src/custom_levels.js` 自訂戰鬥的關卡池
- `src/character.js` 角色造型資料（部位、骨架核心、存檔）；`src/charedit.js` 角色工坊
- `src/generator.js` 隨機任務的地圖產生器；`src/missionsetup.js` 隨機任務設定畫面
- `src/rooms.js` 內建關卡與地圖字元說明；`src/weapons.js` / `src/loadout.js` 武器組裝

本機執行：`python -m http.server 8080`，開 http://localhost:8080（網址加 `?tick` 改用計時器跑主迴圈，視窗被藏起來時除錯用）
